## 1 · What the images are

Twelve path-traced 3D renders (Blender Cycles, built in a scratch folder for this session) of the D-41 concept pieces: The Junction open cuff, The Bellwoods pendant, The Brockton signet and The Lansdowne textured band, plus still lifes and a material close-up. **They are not photographs and not product media.** Every file name starts `pb-standin-`, and every alt text starts "Stand-in render:". The alt text describes only what the picture shows and makes no product claims: no alloy, coating, plating, size or care facts.

They exist only so the preview can be reviewed without empty frames. They never go on the live store (D-52, `phase-5-brief.md` §1 Photography gate). Real photography per `photography-brief.md` (C-09, C-10) replaces every one.

## 2 · The change

1. **Temporary theme assets.** The 12 JPEGs were pushed to the **unpublished** preview theme 196453663042 as `assets/pb-standin-*.jpg` (`theme push --only … --nodelete`), so that Shopify could fetch them from the theme CDN.
2. **Shopify Files.** `fileCreate` with each asset's CDN URL as `originalSource`, `contentType: IMAGE`, the same file name, and `duplicateResolutionMode: RAISE_ERROR`. All 12 reached `READY` at their full size.
3. **Templates** (on the preview and in git), image settings only, merged key by key:

## 4 · Not done: the 12 temporary theme assets

The temporary `assets/pb-standin-*.jpg` copies are **still in the preview theme**. The Admin API delete for theme files is blocked for agents, and the CLI can't delete single files. They are unused (no template or snippet references them), but they must go before this theme is published. Delete them in Admin → Online Store → Themes → (preview) → Edit code → Assets, or let the launch agent do it with the owner present. This is listed in the `phase-5-brief.md` §1 Photography gate.

## 5 · Rollback

1. Templates: restore the image keys from git (`git show <previous commit>:templates/index.json`, and the same for the two page templates), then push them to the preview.
2. Files: delete the 12 `pb-standin-*` files in Admin → Content → Files once no template references them. Tell the owner first (AGENTS.md: deletions).
