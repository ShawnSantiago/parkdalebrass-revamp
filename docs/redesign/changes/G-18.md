## 1 · Why

- D-36: the Journal link must show only the jewelry, material and brand articles. `/blogs/news` lists 101 legacy smoking articles, and a theme can't filter a paginated blog (D-11). A shared tag gives Shopify's built-in filtered URL, `/blogs/news/tagged/journal`.
- E-04 already created both Journal menu items (`jewelry-main-menu`, `footer-learn`) as HTTP links to `/blogs/news/tagged/journal` (D-43). Until the tag exists, that URL is a 404, so G-18 has to be done before launch.
- The change is additive and reversible: `tagsAdd` keeps each article's existing tags and changes no other field. Legacy articles stay published and untouched until the Search Console decision (A-03).

## 3 · The exact change

30 `tagsAdd` calls, one per article, each adding the single tag `journal`. `tagsAdd` adds to the existing tags (it doesn't replace them), so the result is the union: `[]` + `journal` = `["journal"]` for every article here. No other field is sent: title, body, summary, handle, author, image, template suffix and published state are untouched. Nothing else in the store changes (no menu, page, blog setting or theme file).

```graphql
mutation G18Tag($id: ID!, $tags: [String!]!) {
  tagsAdd(id: $id, tags: $tags) {
    node { id ... on Article { handle tags isPublished } }
    userErrors { field message }
  }
}
```

Variables: `{ "id": "<article id>", "tags": ["journal"] }` for each article below.

## 4 · Rollback

1. For each of the 30 article IDs in §3, run:

   ```graphql
   mutation G18Rollback($id: ID!, $tags: [String!]!) {
     tagsRemove(id: $id, tags: $tags) {
       node { id ... on Article { handle tags } }
       userErrors { field message }
     }
   }
   ```

   with `{ "id": "<article id>", "tags": ["journal"] }`. Remove only `journal`; any other tag added later stays.
2. Check `articles(query: "tag:journal")` returns 0 and each article's tags equal the "Tags before" column (all `[]`).
3. `GET /blogs/news/tagged/journal` returns 404 again. **The two Journal menu items from E-04 then lead to a 404**, so before launch either re-tag the articles or point those items elsewhere (an E-04 amendment).

Rolling back changes nothing else: titles, bodies, handles and published state were never touched.
